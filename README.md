# AppVerse

AppVerse is a responsive app discovery marketplace. Browse a curated collection, search and sort by downloads, view app details and review charts, and manage installations saved in your browser.

The 20 app records are stored in `public/data.json`. App icon files used by those records are in `public/app-images/`; update the `image` paths in the JSON when adding or replacing icons.

- CSS
